# API Documentation

Base URL (local): `http://localhost:8000`
Interactive docs: `http://localhost:8000/docs` (auto-generated by FastAPI)

---

## POST /predict_driver_behavior

Raw model prediction — returns the class label and full probability
distribution across all three risk classes.

**Request body**
```json
{
  "driver_id": "DRV-1001",
  "avg_speed_kmh": 95,
  "speeding_events": 5,
  "harsh_braking_events": 4,
  "harsh_acceleration_events": 3,
  "sharp_turns": 2,
  "driving_hours": 9,
  "night_driving_pct": 0.6,
  "phone_usage_events": 2,
  "fatigue_score": 0.7
}
```

**Response**
```json
{
  "driver_id": "DRV-1001",
  "risk_level": "high",
  "risk_probabilities": {"high": 0.90, "low": 0.00, "medium": 0.10},
  "timestamp": "2026-08-20T02:54:51.667713"
}
```

---

## POST /analyze_risk_score

Business-facing endpoint — same input as above, but returns a continuous
0–100 score, the top 3 factors driving the model's decision, and whether
the score crosses the alert threshold (70). **This is the endpoint n8n calls.**

**Response**
```json
{
  "driver_id": "DRV-1001",
  "risk_score": 82.03,
  "risk_level": "high",
  "top_contributing_factors": ["speeding_events", "harsh_braking_events", "driving_hours"],
  "alert_triggered": true,
  "timestamp": "2026-08-20T02:54:51.713262"
}
```

---

## POST /log_data

Persists a result to the database. Called by n8n after every analysis,
regardless of whether an alert fired.

**Request body**
```json
{
  "driver_id": "DRV-1001",
  "risk_level": "high",
  "risk_score": 82.5,
  "source": "n8n"
}
```

**Response**
```json
{"id": 1, "driver_id": "DRV-1001", "risk_level": "high", "risk_score": 82.5, "timestamp": "2026-08-20T02:54:51.723205"}
```

---

## GET /logs?limit=100

Returns recent logged results, newest first. Used by the dashboard (or
you can call it directly to sanity-check what's in the database).

---

## GET /health

```json
{"status": "ok", "model_loaded": true}
```

Useful for n8n or a monitoring tool to check the API is alive before
sending real traffic.

---

## Field reference (input features)

| Field | Type | Meaning |
|---|---|---|
| avg_speed_kmh | float | Average speed for the trip/segment |
| speeding_events | int | Count of times speed exceeded the limit |
| harsh_braking_events | int | Count of sudden hard-braking events |
| harsh_acceleration_events | int | Count of sudden hard-acceleration events |
| sharp_turns | int | Count of aggressive cornering events |
| driving_hours | float | Hours driven in this shift |
| night_driving_pct | float | Fraction (0–1) of the trip driven at night |
| phone_usage_events | int | Count of detected phone-handling events |
| fatigue_score | float | 0 (alert) to 1 (very fatigued) — from a wearable or self-report |
